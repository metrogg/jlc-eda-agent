# JLC EDA Agent

AI 电路读图与设计审查助手 —— 通过自然语言对话，帮你读懂原理图、审查设计并辅助修改。

基于嘉立创 EDA 专业版扩展 API 开发，采用 Tool-Use Loop 架构，LLM 通过调用工具读取当前原理图或全工程网表，再给出解读、审查建议或执行已确认的属性修改。

## 核心能力

### 读图解读

打开任意原理图，AI 可基于读取到的器件、网络与连接关系进行解读：

- 电路整体结构与功能识别
- 器件清单与每个器件的作用
- 信号流向与网络连接关系
- 关键设计参数分析

### 设计审查

AI 可结合 DRC 结果与全工程网表，辅助检查：

- 短路、悬空引脚、未连接网络等基础连接问题
- 电阻值、电容容量等参数是否合理
- 去耦电容、保护电路等设计要素是否齐全
- 器件封装、常用度等可制造性参考

> 审查结论来自 LLM 对 EDA 数据的理解，关键决策仍需结合 datasheets 与工程经验复核。

### 辅助修改

对已确认的调整需求，AI 可调用工具辅助完成：

- 修改器件属性（电阻值、电容值、封装、位号等）
- 删除冗余器件（弹出确认面板，用户确认后执行）
- 搜索器件库并引导交互放置（需用户在原理图中确认位置）

> 目前不支持自动连线；导线、网络标识等绘制操作需要在 EDA 中手动完成。

## 技术架构

```
UI 层（iframe 聊天界面）
    ↓
Agent 循环层（Tool-Use Loop）
    ↓
LLM 适配层（OpenAI / Anthropic / DeepSeek 等）
    ↓
工具执行层（超时保护 + 路由 + 白名单）
    ↓
工具实现层（读 / 写工具集）
    ↓
EDA API 层（eda.* 命名空间）
```

## 工具集

| 工具 | 功能 | 交互 |
|------|------|------|
| `schematic_read` | 读取当前页原理图 | 否 |
| `schematic_review` | 读取全工程网表 + DRC | 否 |
| `component_select` | 搜索立创商城器件库 | 是（选型面板） |
| `component_place` | 引导交互放置器件 | 是（放置确认） |
| `component_modify` | 修改器件属性（阻值、封装、位号等） | 否 |
| `component_delete` | 删除器件 | 是（删除确认面板） |
| `todo_list` | 任务管理 | 否 |

## 开始使用

1. 在嘉立创 EDA 专业版安装并启用插件。
2. 打开顶部菜单 `JLC EDA Agent`，选择 `设置`。
3. 选择平台，填写 `API Key` 和 `Model`。
4. 点击 `验证配置`，通过后点击 `保存`。
5. 选择 `聊天`，开始使用。

## 演示示例

安装配置完成后，在聊天窗口输入以下任意指令即可体验：

```text
帮我解读当前这一页原理图
```

```text
审查一下这个设计有没有问题
```

```text
把 R1 从 10k 改成 4.7k
```

```text
R3 是冗余器件，把它删掉
```

```text
帮我找一个 10uF/0603 的陶瓷电容并放到图里
```

- DeepSeek

- 阿里（通义）
- MiniMax

- Anthropic 兼容（自定义兼容 Anthropic 接口的模型）

## 开发

```bash
# 安装依赖
npm install

# 编译
npm run compile

# 打包成 .eext
npm run build
```

构建产物在 `build/dist/` 目录下，可在嘉立创 EDA 扩展管理器中安装。
